# Synergistic Gas Cascade

## Мета проєкту

Мета головної гілки проєкту — сформулювати та математично перевірити **базову теоремну задачу синергетичного ефекту каскадного розподілу роботи газу**.

На першому етапі розглядається ідеалізований квазістатичний ізотермічний процес. Такий вибір не претендує на опис реального теплового двигуна, а дає просте формальне поле для порівняння двох способів організації однакового газового процесу на одній `P–V`-діаграмі.

## Основна ідея

Розглядаються дві системи:

- **Система А — синхронна система.** Одна порція газу або еквівалентна сукупність робочих органів проходить повний процес розширення синхронно. Усі робочі органи мають однакову поточну стадію процесу.
- **Система Б — каскадна система.** Повний діапазон розширення поділяється на послідовні стадії. Кожна стадія представлена окремим циліндром з окремою порцією газу. Циліндри працюють одночасно, але їхні порції перебувають на різних стадіях розширення. Після завершення робочої стадії порція умовно виводиться, а циліндр послідовно заряджається новою порцією за однакових для обох систем початкових умов.

На цьому етапі заряджання системи приймається як задана умова порівняння. Робота джерела стисненого газу, робота повернення поршнів, тертя, втрати, імпульсні та інерційні явища розглядатимуться в окремих подальших моделях.

## Ідеалізована термодинамічна основа

Для ізотермічного процесу ідеального газу:

```text
P(V) = C / V,
C = P0 * V0.
```

Повна робота розширення однієї порції від початкового об’єму `V0` до кінцевого об’єму `V10` дорівнює площі під ізотермою:

```text
Wповна = integral(P(V) dV, V0..V10)
       = C * ln(V10 / V0).
```

У цій гілці використовується нормований початковий об’єм `V0 = 0` лише як початок геометричного відліку стадії заряджання; власне термодинамічне розширення починається після заряджання, з першого ненульового робочого стану `V1`. Тому для строгого розрахунку роботи межі інтегрування мають бути ненульовими, наприклад `V1..V10`.

## Поділ однієї `P–V`-діаграми на стадії

Нехай для наочного прикладу:

```text
V1 = 1 одиниця об’єму,
V10 = 10 * V1,
P1 = 10 одиниць тиску,
P(V) = P1 * V1 / V.
```

Робочу вісь об’ємів поділяємо вертикальними лініями на десять інтервалів:

```text
0..V1       — стадія введення / заряджання порції;
V1..V2      — перша стадія розширення;
V2..V3      — друга стадія розширення;
V3..V4      — третя стадія розширення;
...
V9..V10     — дев’ята стадія розширення.
```

Якщо потрібно назвати саме десять робочих циліндрів, то їх можна індексувати за станами, які вони представляють:

```text
циліндр 1: V1..V2,
циліндр 2: V2..V3,
...
циліндр 9: V9..V10,
```

Для узгодження з базовим кодом, де `i = 1..10` і `V_i = i * V1 + dV`, десятий індекс є кінцевим станом каскадного вікна. Тому кількість циліндрів, кількість інтервалів та спосіб нумерації повинні бути явно зафіксовані в конкретній версії теореми, щоб не змішувати кількість робочих інтервалів із кількістю граничних станів.

## Адитивність роботи на `P–V`-діаграмі

Якщо робочий діапазон поділено на послідовні інтервали, то повна робота є сумою робіт на цих інтервалах:

```text
Wповна = W1 + W2 + ... + WN,

Wi = integral(P(V) dV, V(i-1)..Vi).
```

Для десяти однакових за шириною інтервалів від `V1` до `V10`:

```text
Wповна = integral(P(V) dV, V1..V10)
       = sum(i=1..9) integral(P(V) dV, Vi..V(i+1)).
```

Ця рівність є звичайною адитивністю визначеного інтеграла. Вона означає, що поділ одного й того самого `P–V`-процесу на стадії не створює додаткової термодинамічної енергії. Сума робіт усіх стадій дорівнює роботі однієї порції газу на тому самому повному діапазоні об’ємів.

Саме це є енергетично нейтральною основою порівняння систем А та Б: відмінність може виникати не з появи нової енергії, а з організації передачі вже наявної роботи постійному зовнішньому навантаженню.

## Критерій порівняння корисної роботи

Для постійної зовнішньої сили:

```text
Wкорисна = Fнавантаження * h.
```

У системі А всі робочі органи проходять однакові стадії одночасно. Якщо сумарна сила стає меншою за навантаження, процес зупиняється; частина теоретично доступного `P–V`-діапазону не використовується під цим навантаженням.

У системі Б робочі органи рознесені по стадіях. У кожний момент часу сумарна сила визначається як:

```text
FБ(dV) = S * sum(i=1..N) [P1 * V1 / (i * V1 + dV)].
```

Тут `S` — площа поршня, `dV` — спільний параметр просування каскадного вікна в межах одного робочого кроку, а `i` — індекс стадії.

Базова гіпотеза полягає в тому, що при однаковому заряджанні та однаковому постійному навантаженні каскадне рознесення стадій може забезпечити більшу відстань дії навантаження і, відповідно, більшу корисну роботу, ніж синхронний режим системи А.

Це твердження потрібно перевіряти окремо від рівності повної `P–V`-роботи. Рівність повної роботи газу не означає автоматичну рівність корисної роботи постійного навантаження, якщо різняться доступна сила, хід і момент зупинки процесу.

## Приклад базових параметрів

```text
P1      = 10 атм
V1      = 1 м3
N       = 10 стадій / робочих позицій
S       = 1 м2
Fload   = 23.99 одиниці сили
```

Для каскадного розподілу початкові стадії мають ефективні об’єми:

```text
V1, 2V1, 3V1, ..., 10V1,
```

і тиски, визначені законом Бойля–Маріотта:

```text
P1, P1/2, P1/3, ..., P1/10.
```

Початкова сумарна сила каскаду в базовій формулі:

```text
FБ(0) = S * P1 * (1 + 1/2 + 1/3 + ... + 1/10)
     ≈ 29.29 одиниці сили.
```

Після цього всі стадії просуваються на величину `dV` від `0` до `V1`. Завершена порція в ідеалізованій циклічній схемі замінюється новою порцією з початковими параметрами. Ця операція заряджання задається як зовнішня умова однакового порівняння систем А та Б.

## Практичний напрям дослідження

Для перенесення гіпотези на механічні конструкції потрібно визначати не лише тиск, об’єм і температуру, а й:

1. кількість робочих позицій;
2. об’ємну або тискову кратність процесу;
3. ширину кожної стадії на `P–V`-діаграмі;
4. початкові фази поршнів;
5. послідовність введення та виведення порцій;
6. спосіб об’єднання сил на спільному валу або іншому вихідному органі;
7. умову, за якої постійне навантаження діє протягом усього заданого ходу;
8. окремо — втрати, інерцію, імпульси, потужність і енергетичну вартість заряджання.

Це дозволяє сформулювати подальшу базову теоремну задачу:

> За однакової повної `P–V`-роботи та однакових умов заряджання визначити, чи може просторово-часове каскадне розподілення стадій розширення збільшити корисну роботу постійного зовнішнього навантаження порівняно із синхронним проходженням того самого термодинамічного процесу.

Ця задача не стверджує порушення закону збереження енергії. Вона вимагає роздільного порівняння:

```text
1. повної термодинамічної роботи газу;
2. корисної роботи зовнішнього навантаження;
3. роботи та енергії заряджання;
4. механічних і динамічних втрат;
5. потужності та імпульсних характеристик.
```

Поточна гілка розглядає лише перші два пункти в ідеалізованому базовому наближенні.
