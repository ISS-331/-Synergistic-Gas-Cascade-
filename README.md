# -Synergistic-Gas-Cascade-
Новий математичний підхід до розділу термодинаміки «Робота газу» Цей репозиторій містить математичну модель, яка доводить неефективність класичного синхронного розширення газу в поршневих системах при роботі під сталим навантаженням. Модель демонструє метод повного вилучення потенційної енергії газу через створення взаємозв'язаного каскаду об'ємів.
