# Synergistic Gas Cascade

## Стисла стаття-формула

### Постановка проблеми

У реальному газовому двигуні або компресорі повна теоретична робота розширення не завжди перетворюється у корисну роботу. Причина тому наявність навантаження. Тобто окрім дисипативних втрат, існує взаємопов'язане обмеження: зі збільшенням швидкості поршень віддаляється від квазістатичного режиму, а саме, зі збільшенням навантаження зменшуються швидкість і доступний хід. Якщо поточна сила газу поступово меншає та стає рівною силі навантаження, то розширення припиняється ще до досягнення кінцевого об'єму без навантаження. Це називається проблемою неповного розширення під навантаженням.

### Гіпотеза

Нехай повний діапазон ізотермічного розширення робочого тіла поділено на `N` робочих стадій. Кожна стадія представлена окремим циліндром з окремою порцією газу. Поршні працюють одночасно, але перебувають на різних стадіях розширення; їхні штоки передають сили на спільний вихідний механізм.

Гіпотеза полягає в тому, що таке каскадне рознесення стадій може довше підтримувати задану постійну силу навантаження і тому забезпечити більший робочий хід та більшу корисну роботу, ніж синхронна система з такою самою кількістю робочих органів і такими самими умовами заряджання.

### Доведення в моделі

Для ізотермічного процесу:

```text
P(V) = C / V,        C = P_start * V_start.
```

Повна робота однієї порції на діапазоні `V_start..V_end`:

```text
W_PV = integral(P(V) dV, V_start..V_end)
     = C * ln(V_end / V_start).
```

Якщо той самий діапазон розділити на послідовні інтервали, адитивність інтеграла дає:

```text
W_PV = W_1 + W_2 + ... + W_N.
```

Отже, каскадний поділ не створює нової енергії: повна `P–V` робота залишається тією самою. Різниця стосується корисної роботи постійного навантаження:

```text
W_A = F_load * h_A,
W_B = F_load * h_B.
```

Якщо за однакового `F_load` каскадна схема забезпечує `h_B > h_A`, то:

```text
W_B / W_A = h_B / h_A > 1.
```

Це є умовним доведенням гіпотези в межах прийнятої моделі. Для доведення теореми про конкретний реальний пристрій додатково потрібно перевірити кінематичний зв'язок із загальним валом/штоком, правило заміни порцій, роботу заряджання, імпульси, інерцію та втрати.

### Висновок

Каскадна система не збільшує повну термодинамічну енергію газу. Її гіпотетична перевага полягає в іншій організації передачі тієї самої `P–V` роботи: різні порції підтримують різні стадії розширення одночасно, що в ідеалізованій моделі може збільшити хід постійного навантаження до моменту його зупинки.

## Базовий приклад

Приймаємо:

```text
P1      = 10 атм
V1      = 1 м³
N       = 10 робочих позицій
S       = 1 м²
F_load  = 23.99 одиниці сили
```

Для каскадної системи Б у поточний момент представлені стадії з ефективними об'ємами:

```text
V1, 2V1, 3V1, ..., 10V1.
```

За законом Бойля–Маріотта їхні тиски:

```text
P1, P1/2, P1/3, ..., P1/10
= 10, 5, 3.33, 2.5, ..., 1 атм.
```

Сумарна сила каскаду:

```text
F_B(dV) = S * sum(i=1..N) [P1 * V1 / (i * V1 + dV)].
```

При `dV = 0`:

```text
F_B(0) = P1 * (1 + 1/2 + ... + 1/10)
       ≈ 29.29 одиниці сили.
```

Для синхронної системи А код використовує:

```text
F_A_init = N * P1 * S
F_A(h)   = F_A_init / (1 + h)
h_A      = F_A_init / F_load - 1
```

Каскадна схема має умовний хід:

```text
h_B = N * (V1 / S).
```

За заданими формулами:

```text
h_B ≈ 10
h_A ≈ 3.17
W_B / W_A ≈ 3.16.
```

Значення `3.16` є результатом саме цієї базової моделі, а не універсальною константою.

## Терміни

- **Порція газу** — функціонально відокремлена кількість робочого тіла в окремому циліндрі.
- **Вхідна порція** — порція з початковими параметрами, наприклад `P_max`, `V_min`.
- **Робоча порція** — порція, яка зараз створює силу та виконує роботу.
- **Вихідна порція** — порція, що завершила задану робочу ділянку.
- **Введення порції** — послідовне надходження нової порції до звільненої робочої позиції.
- **Виведення порції** — вилучення порції після завершення робочої ділянки.
- **Стадія заряджання** — підготовка порції до роботи. Вона не входить автоматично до кількості робочих стадій: це залежить від типу машини та меж системи.
- **Об'ємна кратність** — `K_V = V_max / V_min`.
- **Тискова кратність** — `K_P = P_max / P_min`; для ізотермічного процесу `K_P = K_V`.
- **Робоча стадія кратності** — окремий інтервал зміни об'єму і тиску, представлений робочою позицією каскаду.
- **Каскадна система** — незалежні циліндри, порції яких одночасно перебувають на різних послідовних стадіях.
- **Синергетичний ефект** — гіпотетичне збільшення корисної роботи постійного навантаження завдяки рознесенню стадій і послідовному оновленню робочих позицій.
- **Проблема неповного розширення** — зупинка або відхилення від повного `P–V`-процесу через падіння сили нижче навантаження або через неквазистатичну динаміку.
- **Повна `P–V` робота** — `W_PV = integral(P(V) dV)`.
- **Корисна робота навантаження** — `W_корисна = F_load * h`.

## Межі базової моделі

Заряджання систем А та Б приймається однаковою зовнішньою умовою. Енергія джерела стисненого газу, повернення поршнів, тертя, витоки, теплообмін, імпульси, інерція та потужність поки не включені до порівняння. Вони мають бути предметом окремих гілок дослідження.
